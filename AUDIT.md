# Аудит неиспользуемых функций

Ниже перечислены функции, которые не используются в приложении. Вызовы из тестов не учитываются.

| Название функции | Где находится | Полезная ли она? (Да/Нет) | Как её можно использовать в будущем? (Идея для фичи) |
| :--- | :--- | :--- | :--- |
| `calculateAverageYear` | `src/task1-types.ts` | Да | Тем самым можно будет собирать статистику по годам в коллекции |
| `addBook` | `src/task2-functions.ts` | Да | Можно будет добавлять книги из файла в отдельный каталог, не меняя исходные данные |
| `removeBook` | `src/task2-functions.ts` | Да | Можно будет убирать лишние книги перед импортом, сохраняя исходный каталог |
| `getBook` | `src/task2-functions.ts` | Да | С её помощью можно будет искать книгу по id и проверять, есть ли она уже в каталоге |
| `filterByMinRating` | `src/task3-filters.ts` | Да | Тем самым можно будет отбирать книги по минимальному рейтингу |
| `filterAndSortBooks` | `src/task5-utils.ts` | Да | Можно будет сразу искать и сортировать книги перед добавлением в основную коллекцию |
